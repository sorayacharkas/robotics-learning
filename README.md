# robotics-learning

My C++ practice, plus small exercises on the way to robotics software (ROS 2, simulation, vision).

```
inc/   headers
src/   exercises (main.cpp is my scratchpad for the current chapter)
```

Build and run a file:

```bash
g++ -std=c++20 -Iinc src/main.cpp -o build/main && ./build/main
```
